# mark-readnotes 功能规格（功能 ↔ 板块 ↔ 按键 ↔ 判据）

产品目标：**对网页 / 视频 / 论文阅读时随手记的「随笔」**。以后可能加入别的功能，因此第一版就把
「随笔」做成一个独立板块，界面与数据都按可扩展来摆。

## 1. 归类集合（一个功能只属于一个集合）

| 集合 | 职责 | 本版功能 |
|---|---|---|
| 随笔（笔记） | 记、读、改随笔 | 块列表、白板编辑、标签搬家、新建块 |
| 存储 | 文件往哪写、索引怎么来 | 目录授权、懒扫描索引、写回 md |
| 设置 | 应用级配置 | 显示笔记根、强制刷新索引 |
| （预留） | 以后的功能板块 | 导出 / WebDAV / 别的功能——先在抽屉里留位置，不摆假控件 |

## 2. 载体与按键（常驻按键 ≤ 3）

### 板块 A：主页 = 最近编辑的块

| 项 | 规格 |
|---|---|
| 载体 | 一屏列表，卡片 = 一个块，按 `updated_at` 倒序 |
| 卡片内容 | 归档栏（一级标题，独立底色/等宽，与正文隔离）+ 标签行 + 正文前几行；**每卡最高高度固定**（超出截断，不撑破一屏） |
| 按键 1 | 「＋ 新随笔」：新建一个空块，直接进白板 |
| 按键 2 | 「设置」：弹出小窗（笔记根路径 / 刷新索引 / 版本号） |
| 点卡片 | 从底部弹出**全屏白板**（占据整屏，不是小窗、不是半屏），开始编辑 |
| 空态 | 一句话：「先选笔记目录，然后点＋新随笔」 |

### 板块 B：白板（全屏编辑，覆盖层）

| 项 | 规格 |
|---|---|
| 形态 | 从底部弹起的全屏覆盖层；顶部一条工具栏，其余全给编辑区 |
| 归档区 | 一级标题单独一行（输入框，样式与正文明显不同）；下一行是标签输入（多个标签，空格分隔） |
| 正文区 | markdown 编辑区；「预览」切换渲染视图（图片、链接、基本 HTML、TeX 由渲染器出） |
| 按键 | ≤3：「完成」（收白板）/「预览」（编辑↔渲染）/「⋯」（删除本块，收进小窗，不常驻） |
| 保存 | 离开白板即保存；写回 md → 更新 SQLite；标签改了 → 块搬到新文件 |
| 返回键 | 先收白板（由前端决定），再退出应用 |

### 板块 D：渲染（正文的显示规则）

| 项 | 规格 |
|---|---|
| markdown | 标题、粗体/斜体、行内代码、代码块、引用、有序/无序列表、分割线、链接、图片 |
| 数学公式 | 本机内置 KaTeX（离线、零外网依赖）：`$…$` 行内、`$$…$$` 单行或多行、`\(…\)`、`\[…\]`；坏公式显示原文成红色，不让页面炸 |
| 图片 | ① 带协议的地址（http/https/data:）按原样交给 WebView；② 其余（相对路径、`./`、子目录）**按笔记根解析**：`/file/<相对路径>` → 原生用 SAF 取出字节流式返回，找不到就 404（页面里表现为图裂，不静默当成功） |
| 基本 HTML | 放行，但先过一遍消毒：`script/iframe/object/embed/link/meta/base/form/frame/frameset/applet` 一律移除，`on*` 事件属性与 `javascript:`/`vbscript:`/`data:text/html` 地址被剥掉（笔记内容不能借原生桥动文件） |
| 链接跳转 | 点链接交给系统浏览器（op `ui.open`），应用内不做内嵌浏览 |
| 代码块 | ``` 围栏内的内容不参与公式/图片/HTML 处理 |

### 板块 F：导出（按标签）

| 项 | 规格 |
|---|---|
| 入口 | 主页顶栏「导出」（主页常驻按键 3 个：导出、设置、＋新随笔） |
| 规则 | 第 1 个标签＝一级目录、第 2 个＝二级目录（第 3 个及以后不建目录，但原样留在文件里）；文件名＝一级标题；同级重名加 `-2` |
| 排除 | 小窗里可点选标签当排除项：带**任一**排除标签的块整体不导出（不建目录、不写文件） |
| 导出并预览 | 列出将生成的文件树（目录 + 文件名），**不写盘**；之后才出现「写入目录」「系统分享」 |
| 直接导出 | 跳过预览，直接写盘（首次会先弹系统目录选择器） |
| 写入目录 | 用户选的目录 + 应用自建英文子目录 `mark-readnotes-export`；同名文件覆盖（不堆副本） |
| 系统分享 | 先写到应用缓存 `cache/share/…`，再经 FileProvider 一次性授权交给 `ACTION_SEND_MULTIPLE`（单文件时 `ACTION_SEND`） |
| 文件名/目录名 | 取标签与标题原文（含中文），只挡掉 `\ / : * ? " < > |` |

### 板块 E：设置小窗

| 项 | 规格 |
|---|---|
| 载体 | 点「设置」弹出的底部小窗，只放信息 + 极少数动作 |
| 内容 | 笔记根（只读文本）、文件数/块数（读 SQLite）、最近扫描时间、刷新索引（按键）、重新选择目录（按键）、版本号 |
| 层级 | 小窗必须盖在白板上（`#sheet` z-index 高于 `#board`）——它就是从白板里点开的 |

## 3. 本版明确不做（写清缺口，不当已完成）

- 导出、WebDAV、图片插入、TeX 之外的复杂渲染（KaTeX 本地包在后续轮次接入）
- 抽屉里的其它功能板块：只留位置与登记，不摆点不动的假控件
- 块内搜索、标签筛选：后续轮次（筛选只作为主页的一个入口，不占常驻按键）

## 4. 验收判据（每条都能读回来）

| 编号 | 功能点 | 判据（读回来的事实） |
|---|---|---|
| F1 | 目录授权 | SQLite `source` 有 1 行，`tree_uri` 非空；根目录里出现 `mark-readnotes/` 目录 |
| F2 | 新建块落盘 | 新建并输入标题/标签/正文后：`adb shell` 能读到 `<tag>.md` 里含该标题与标签行；`block` 表计数 +1 |
| F3 | 主页列出最近编辑 | CDP 读主页 DOM 文本，含刚编辑块的标题；卡片高度 ≤ 设定上限（读 `getBoundingClientRect`） |
| F4 | 白板是全屏且非小窗 | CDP 读白板容器 `getBoundingClientRect`：宽≈屏宽、高≈屏高（误差 ≤ 8px），且 z-index 在列表之上 |
| F5 | 改第一个标签 = 搬家 | 把第一个标签从 `web` 改成 `paper`：`web.md` 里不再含该块，`paper.md` 里含该块；`block.file_id` 指向 `paper.md` 的行 |
| F6 | 懒扫描 | 冷启动日志含 `scan=skipped(reason=startup)`；主页仍有数据（只读 SQLite）；主动点刷新才出现目录遍历日志 |
| F7 | 归档与正文隔离 | DOM 里标题与标签行位于独立容器（class `b-arch`），不在正文 `b-body` 内 |
| F8 | 公式渲染 | `mrState().tex` = `{total, ok, failed}` 且 `#preview .katex` 数 = ok；display 公式有 `.katex-display`；坏公式有 `.katex-error` 且显示原文 |
| F9 | 本地图片 | `#preview img` 的 `src` 指向 `/file/<相对路径>`，且 `complete && naturalWidth>0`；原生日志有 `img.serve rel=… mime=…` |
| F10 | 网络图片 | 同上，`src` 是 http(s) 直链，`naturalWidth>0`；能读到服务端访问日志一行 |
| F11 | HTML 消毒 | `window.__sanitize.removedTags/removedAttrs` 计数；DOM 里无 `script/iframe`、无 `on*` 属性、无 `javascript:` 链接；正常图片仍在 |
| F12 | 小窗层级 | `#sheet` 的 z-index > `#board`；`elementFromPoint(小窗按键中心)` 命中的是那个按键 |
| F13 | 导出目录层级 | `exp.plan` 的 `tree` 里出现 `法规/标准(1)`、`法规/2024(1)`；第 3 个标签不建目录 |
| F14 | 排除标签 | 点掉某标签后 `excluded` 计数 +1、`files` −1，预览树里对应目录消失 |
| F15 | 预览不写盘 | 预览后目标目录仍不存在（`ls -d` 报 No such file or directory） |
| F16 | 写入目录 | 盘上出现按标签的目录树 + 标题命名的 md，内容＝块原文（标签一个不少） |
| F17 | 重复导出 | 第二次 `new=0, overwritten=N`（覆盖，不产生 `-2` 副本） |
| F18 | 系统分享 | 日志 `exp.share(action=ACTION_SEND_MULTIPLE,target=…)` 且前台窗口变成系统选择器；缓存里生成同结构文件 |
