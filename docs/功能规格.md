# mark-readnotes 功能规格（功能 ↔ 板块 ↔ 按键 ↔ 判据）

产品目标：**对网页 / 视频 / 论文阅读时随手记的「随笔」**。以后可能加入别的功能，因此第一版就把
「随笔」做成一个独立板块，界面与数据都按可扩展来摆。

## 1. 归类集合（一个功能只属于一个集合）

| 集合 | 职责 | 本版功能 |
|---|---|---|
| 随笔（笔记） | 记、读、改随笔 | 块列表、白板编辑、标签搬家、新建块 |
| 存储 | 文件往哪写、索引怎么来 | 目录授权、懒扫描索引、写回 md |
| 设置 | 应用级配置 | 显示笔记根、强制刷新索引 |
| （预留） | 以后的功能板块 | 导出 / WebDAV / 别的功能——先在抽屉里留位置，不摆假控件 |

## 2. 载体与按键（常驻按键 ≤ 3）

### 板块 A：主页 = 最近编辑的块

| 项 | 规格 |
|---|---|
| 载体 | 一屏列表，卡片 = 一个块，按 `updated_at` 倒序 |
| 卡片内容 | 归档栏（一级标题，独立底色/等宽，与正文隔离）+ 标签行 + 正文前几行；**每卡最高高度固定**（超出截断，不撑破一屏） |
| 按键 1 | 「＋ 新随笔」：新建一个空块，直接进白板 |
| 按键 2 | 「设置」：弹出小窗（笔记根路径 / 刷新索引 / 版本号） |
| 点卡片 | 从底部弹出**全屏白板**（占据整屏，不是小窗、不是半屏），开始编辑 |
| 空态 | 一句话：「先选笔记目录，然后点＋新随笔」 |

### 板块 B：白板（全屏编辑，覆盖层）

| 项 | 规格 |
|---|---|
| 形态 | 从底部弹起的全屏覆盖层；顶部一条工具栏，其余全给编辑区 |
| 归档区 | 一级标题单独一行（输入框，样式与正文明显不同）；下一行是标签输入（多个标签，空格分隔） |
| 正文区 | markdown 编辑区；「预览」切换渲染视图（图片、链接、基本 HTML、TeX 由渲染器出） |
| 按键 | ≤3：「完成」（收白板）/「预览」（编辑↔渲染）/「⋯」（删除本块，收进小窗，不常驻） |
| 保存 | 离开白板即保存；写回 md → 更新 SQLite；标签改了 → 块搬到新文件 |
| 返回键 | 先收白板（由前端决定），再退出应用 |

### 板块 C：设置小窗

| 项 | 规格 |
|---|---|
| 载体 | 点「设置」弹出的底部小窗，只放信息 + 极少数动作 |
| 内容 | 笔记根（只读文本）、块总数/文件数（读 SQLite）、刷新索引（按键）、版本号 |
| 换目录 | 一个按键「重新选择目录」（不常驻在主页） |

## 3. 本版明确不做（写清缺口，不当已完成）

- 导出、WebDAV、图片插入、TeX 之外的复杂渲染（KaTeX 本地包在后续轮次接入）
- 抽屉里的其它功能板块：只留位置与登记，不摆点不动的假控件
- 块内搜索、标签筛选：后续轮次（筛选只作为主页的一个入口，不占常驻按键）

## 4. 验收判据（每条都能读回来）

| 编号 | 功能点 | 判据（读回来的事实） |
|---|---|---|
| F1 | 目录授权 | SQLite `source` 有 1 行，`tree_uri` 非空；根目录里出现 `mark-readnotes/` 目录 |
| F2 | 新建块落盘 | 新建并输入标题/标签/正文后：`adb shell` 能读到 `<tag>.md` 里含该标题与标签行；`block` 表计数 +1 |
| F3 | 主页列出最近编辑 | CDP 读主页 DOM 文本，含刚编辑块的标题；卡片高度 ≤ 设定上限（读 `getBoundingClientRect`） |
| F4 | 白板是全屏且非小窗 | CDP 读白板容器 `getBoundingClientRect`：宽≈屏宽、高≈屏高（误差 ≤ 8px），且 z-index 在列表之上 |
| F5 | 改第一个标签 = 搬家 | 把第一个标签从 `web` 改成 `paper`：`web.md` 里不再含该块，`paper.md` 里含该块；`block.file_id` 指向 `paper.md` 的行 |
| F6 | 懒扫描 | 冷启动日志含 `scan=skipped(reason=startup)`；主页仍有数据（只读 SQLite）；主动点刷新才出现目录遍历日志 |
| F7 | 归档与正文隔离 | DOM 里标题与标签行位于独立容器（class `b-arch`），不在正文 `b-body` 内 |

## 5. 稳定标识（测试与自检用）

- 页面：`#home`、`#board`、`.card`、`.card .b-arch`、`.card .b-body`、`#btn-new`、`#btn-settings`、
  `#board .b-arch input`、`#board textarea`、`#btn-done`、`#btn-preview`
- op 层（原生）：`app.info` / `src.pick` / `src.get` / `idx.refresh` / `idx.stats` / `idx.blocks` /
  `idx.files` / `blk.get` / `blk.save` / `blk.new` / `blk.delete`
- 版本标记：页面 `<body data-build="…">`，原生 `app.info.build`
