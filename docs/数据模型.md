# 数据模型（mark-readnotes）

## 1. 权威源只有一处

| 数据 | 权威源 | SQLite 的角色 |
|---|---|---|
| 笔记正文（块） | **磁盘上的 .md 文件** | 索引缓存（heading/tag/body/字数/file mtime+size） |
| 索引与最近编辑顺序 | **SQLite** | 权威 |
| 笔记根目录授权 | SQLite `source.tree_uri`（SAF 持久授权） | 权威 |

写入路径固定一条：**白板保存 → 先改 .md 文件 → 再同步 SQLite 缓存行**。
读取路径：主页/列表**只读 SQLite**（不碰文件、不扫目录）；打开白板时按需校验那**一个**文件的 mtime/size。

## 2. 块与文件的划分规则（用户 2026-09-22 确认）

md 文件内容形如：

```markdown
# 第一篇随笔的标题
#web #paper
正文……（可含图片、链接、HTML、TeX）

# 第二篇随笔的标题
#web
正文……
```

规则：

1. **一级标题（`# `）分块**：一个块 = 从某行 `# 标题` 起，到下一个 `# 标题` 之前（或文件结束）。
2. **标签行 = 一级标题后面紧跟的第一行**，一行可以写**多个**标签（`#web #paper`）。
3. **归属文件由该标签行里的第一个标签决定**：第一个标签 = `web` → 块属于 `<根>/web.md`。
   - 判定不依赖“行号正好是第几行”：实现在块内按行顺序找第一个含标签的行，取该行第一个标签
     （用户纠正过：“第一个 tag 文本不是第一行”，所以不做“必须紧邻标题”的硬判定，避免误判成无标签）。
4. **改第一个标签 = 整块搬家**：把块从旧文件删除、按新标签追加到新文件末尾，SQLite 的 `block.file_id`
   随之更新。标签行里其余标签只是备注，不参与归属。
5. 块里一个标签都没有 → 归入默认文件 `unsorted.md`（默认标签 `unsorted`）。

### 文件名映射（目录/文件名一律 ASCII，用户要求）

- `tag` 匹配 `^[A-Za-z0-9][A-Za-z0-9._-]*$` → 文件名 `<tag>.md`
- 其它（含中文标签）→ 文件名 `t-<sha1(tag) 前8位>.md`，原标签仍存在 md 里，界面显示原标签
- 笔记根 = 用户选定的可见目录下的 **`mark-readnotes`** 子目录（首次授权时自动创建）
  —— 目录名固定英文，避免中文目录。

## 3. SQLite 结构（v1，手写 SQLiteOpenHelper，无 Room）

```sql
CREATE TABLE source(          -- 已授权的存储来源
  id INTEGER PRIMARY KEY, tree_uri TEXT UNIQUE, root_name TEXT,
  kind TEXT,                  -- saf | local | webdav(后续)
  added_at INTEGER, last_scan_at INTEGER);

CREATE TABLE note_file(       -- 一个 md 文件 = 一个归档
  id INTEGER PRIMARY KEY, source_id INTEGER,
  doc_uri TEXT UNIQUE, doc_id TEXT, name TEXT, tag TEXT,
  size INTEGER, mtime INTEGER, last_scan_at INTEGER,
  present INTEGER DEFAULT 1);

CREATE TABLE block(           -- 一个块 = 一条随笔
  id INTEGER PRIMARY KEY, file_id INTEGER, doc_uri TEXT,
  heading TEXT,               -- 一级标题文本（归档栏）
  tag TEXT,                   -- 第一个标签（= 归属）
  body TEXT,                  -- 去掉标题与标签行后的正文
  raw TEXT,                   -- 完整块原文（写回时以此为底）
  char_count INTEGER,
  block_index INTEGER,        -- 在文件内的顺序
  updated_at INTEGER,         -- 最近编辑（主页排序用）
  file_mtime INTEGER, file_size INTEGER,   -- 写回时的文件状态，用于懒校验
  present INTEGER DEFAULT 1);

CREATE INDEX idx_block_updated ON block(updated_at DESC);
CREATE TABLE meta(key TEXT PRIMARY KEY, value TEXT);
```

## 4. 懒扫描（用户要求：不全局扫目录、结果永久保留）

- **冷启动只读 SQLite**，绝不枚举目录（本地与 WebDAV 一样）。日志里打 `scan=skipped(reason=startup)`。
- 目录枚举只在这三种时机发生：
  1. 首次授权后的那一次初始枚举（全部文件建索引）；
  2. 用户在白板/主页**主动点「刷新」**；
  3. 打开某一个块所属文件前，对该文件做 `mtime/size` 比对（不一致才重解析该文件）。
- 索引**永久保留**：文件暂时读不到（免打扰、网盘离线、权限被撤）时 `present=0`，行不删，界面照常显示，
  标注“离线”；用户显式删除才删行。
- 网络存储器（WebDAV/SMB）走同一套规则：只按需取单个文件，永不整目录遍历。
