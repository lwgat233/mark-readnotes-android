- 五板块的完整跑（47 条）是在 **`0.1.0+r6`** 上做的；随后只改了**自检规则**（计划中的板块不算“界面空集合”），

  归档构件是 r7 这一份，两轮读数都在 `evidence/` 里。
- 分板块脚本自己也踩过坑（都改掉了，见 `docs/问题与需求登记.md` P10–P12）：
  PATH 里少了 node → 一片假红；点链接/分享把应用挤到后台被杀 → 探针连不上；
  浮层里滚出屏幕的键按 rect 点会 `Position out of bounds`。
