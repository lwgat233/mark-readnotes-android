## B. 交互缺口（没有交互 = 没做）

- 块之间手动排序（现在只能靠改内容间接影响顺序）
- 撤销/回收站（删除是两步确认 + 真删）
- 主页没有“离线文件”的状态行（数据里有 `offline` 标记，界面还没用起来）
- 表格/任务列表这类 markdown 扩展没渲染（现在按普通段落处理）

## C. 测试缺口

- 未测真机（只在 emulator-5554 上跑过）
- 未测 Doze/长时间后台、进程被杀后的索引一致性
- 未测换目录后的旧索引清理（代码里会整表重建，但没跑用例）
- 未测大文件（几千块）下主页与白板的表现
- 图片只验了 png；jpg/webp/gif/heic 走同一段 MIME 映射但未逐个验

## D. 已知限制（不是缺陷，但要写清）

- 白板保存是**整文件重写**（SAF 没有原子替换/rename）；文件很大时会有一次全量写入
- 编辑会更新该文件 mtime → “外部同时改同一个文件”仍是最后写入者赢，无冲突合并
- 标签 → 文件名只支持 ASCII；中文标签落成 `t-<sha1 前8位>.md`（原标签仍存在 md 里）
- 壳子走 http 虚拟源 + `usesCleartextTraffic=true`（为放行 http 图源，见问题登记 P5）：
  页面不是安全源，将来要用 `crypto.subtle`/service worker 这类能力时得重新权衡
- 渲染放行“基本 HTML”，但会剥掉脚本类标签与事件属性（这是有意的：笔记内容不能借桥动文件）
