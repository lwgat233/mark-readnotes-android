# 缺口清单（= 开发不足的判据，逐轮消）

## A. 功能缺口（用户明确要过、本版没做）

| 编号 | 缺口 | 说明 |
|---|---|---|
| R1 | TeX 渲染 | 现在 `$…$` 只按原文显示（`.tex` 样式）。要接本机内置 KaTeX 资源，不联网 |
| R2 | 导出 | 一键导出（整目录 / 单文件 / 单块），用户提过「支持导出」 |
| R3 | WebDAV | 网络存储器支持；规则与本地一致：只按需取单文件、索引永久保留、离线标 present=0 |
| R4 | 图片 | https 图片可显示；**本地相对路径图片**（要经 SAF 读进来）与 **http 图片**（被 mixed content 拦）目前不可用 |
| R5 | 主页筛选与搜索 | 标签筛选、块内全文搜索（收进设置小窗，不占常驻按键） |
| R6 | 其它功能板块 | 抽屉里留位置与登记，不摆点不动的假控件；用户提过「以后可能添加其他功能」 |
| R7 | 外部控制口 | op 层已按「一套给所有入口用」写，但还没开 HTTP 口；开了才谈得上「接口也能验」 |
| R8 | 懒加载列表 | 主页现在一次取 60 条；块多了要分页/滚动增量加载 |

## B. 交互缺口（没有交互 = 没做）

- 块之间的手动排序（现在只能靠改标签/改内容间接影响顺序）
- 白板里插入图片的入口（没有图片就只能手写相对路径）
- 撤销/回收站（现在删除是两步确认 + 真删，没有撤销）
- 主页没有任何“正在扫描/离线”的状态行（离线文件只在数据里有 `offline` 标记，界面还没用起来）

## C. 测试缺口

- 未测：真机（只在 emulator-5554 上跑过）
- 未测：Doze/长时间后台、进程被杀后的索引一致性
- 未测：多来源（换目录）的旧索引清理（代码里会整表重建，但没跑过用例）
- 未测：大文件（几千块）下主页与白板的表现

## D. 已知限制（不是缺陷，但要写清）

- 白板保存是**整文件重写**（SAF 没有原子替换/rename）：文件很大时会有一次全量写入
- 每次编辑都会更新该文件的 mtime，所以“外部同时改同一个文件”仍是最后写入者赢（无冲突合并）
- 标签 → 文件名只支持 ASCII；中文标签会变成 `t-<sha1 前8位>.md`（原标签仍存在 md 里）
