## F13 目录层级 = 标签顺序

```
node tools/webview-cdp.mjs eval '(async()=>{const p=await call("exp.plan",{exclude:[]}); return {files:p.files,blocks:p.blocks,dirs:p.dirs,tree:p.tree.map(g=>g.dir+"("+g.count+")")};})()'
```
实测：`{"files":6,"blocks":6,"dirs":5,"tree":["web(1)","paper(2)","法规/标准(1)","法规/2024(1)","视频/RAG(1)"]}`
→ 第 1 个标签＝一级目录、第 2 个＝二级目录；第 3 个标签（如 `#2024` 在 `#法规 #标准 #2024` 里）**不建目录**。**通过**

## F16 写入目录（首次选目录 → 自动继续）

```
（界面）点「写入目录」→ 系统目录选择器 → 选 Documents → USE THIS FOLDER → ALLOW
adb shell "ls -R /sdcard/Documents/mark-readnotes-export"
```
实测日志：`exp.pick opened` → `exp.attach(picked=Documents,root=primary:Documents/mark-readnotes-export)` →
`saf.mkdir name=web / paper / 法规 / 标准 / 2024` → `exp.write(dir=Documents/mark-readnotes-export,files=5,new=5,over=0,dirs=5,ms=690)`
盘上结构（见 `evidence/r3-export-tree.txt`）：
```
paper/KaTeX 与图片验证.md、paper/PagedAttention 论文要点.md
web/视频随手记：KV Cache 那期.md
法规/2024/2024 年的修订说明.md、法规/标准/标准 A 的要点.md
视频/RAG/B 站那期讲 RAG 的视频.md        ← 「直接导出」（没排除）那次补上的
```
抽样文件 `evidence/r3-export-sample.md`：
```

标准里说清楚了适用范围。

- 第二条：不适用
```
→ 目录名＝标签原文、文件名＝标题原文、**内容＝块原文、三个标签一个没丢**（导入时才能原样归位）。**通过**

## F18 系统分享

```
（界面）点「系统分享」
adb shell logcat -d -s markreadnotes | grep exp.share
adb shell dumpsys window | grep mCurrentFocus
adb shell "run-as dev.markreadnotes ls -R cache/share"
```
实测：`exp.prepare(files=5,dir=/data/user/0/dev.markreadnotes/cache/share)` →
`exp.share(uris=5,action=android.intent.action.SEND_MULTIPLE,target=com.google.android.gms)`；
前台窗口变成 `com.android.intentresolver/com.android.intentresolver.ChooserActivity`（系统分享面板真的起来了）；
缓存里按标签结构生成 5 个 md；页面提示「已交给系统分享：5 个文件」。
**注**：模拟器里只有 GMS 能接 markdown 分享，没有微信/文件管理器之类；真机上目标列表会不同，判定看的是“选择器起来了 + 目标列表非空”。**通过**
