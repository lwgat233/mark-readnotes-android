# 问题与需求登记（mark-readnotes）

格式：现象 / 根因 / 修法 / 证据 / 状态。新的往下加。

## P1 新建块时标签被粘成 `unsortedweb`（已修）

- **现象**：新建块时标签框预填 `unsorted`，用户直接输入 `web` 得到 `unsortedweb`，块被写进 `unsortedweb.md`。
  真机复现：测试脚本输入 `web`，落盘文件是 `unsortedweb.md`。
- **根因**：`openBoard(null)` 用 `fillBoard('', DEFAULT_TAG, '')` 预填默认标签，短字段又不全选，
  输入等于在默认值后面追加。
- **修法**：新块标签预填「上次用过的标签」，没有就留空（留空即归 `unsorted.md`，由提示行说明）；
  标签框聚焦时全选（`focus → select()`），打字即替换。标题/正文不受影响。
- **证据**：改后同一路径实测 `#ed-tags` 值从 `unsortedweb` →（点入后）输入 `web` → 值恰为 `web`，
  落盘 `web.md`、`unsortedweb.md` 被删（见 `docs/验收清单-第1轮.md` F5）。
- **状态**：已修并复验。

## P2 返回键“没反应”的读数存疑（已澄清，非缺陷）

- **现象**：第一次测「按返回键收白板」时读到 `boardOpen=true`，看着像返回键失效。
- **排查**：那一轮的前一个动作刚把链接交给系统浏览器，前台曾被打断；当时也没有日志可判断是否进到 `onBackPressed`。
  给 `onBackPressed` 加了 `back.enter` / `back.js=` 日志后，清干净前台重测。
- **结果**：真返回键 → `back.js="1" handled=true finished=false`，白板关闭、应用进程不退出。链路正常。
- **状态**：已澄清（原读数归因于当时前台环境，不当作已修缺陷汇报）。

## P3 SAF 不能选存储根目录（设计已适配）

- **现象**：`ACTION_OPEN_DOCUMENT_TREE` 停在内置存储根时，系统显示
  "Can't use this folder / To protect your privacy, choose another folder"。
- **处置**：不跟系统对抗。默认引导用户选一个子目录（如 Documents），应用在其中**自建** `mark-readnotes` 子目录，
  目录名固定英文（用户要求）。初始 URI 仍指向存储根，减少用户点击。
- **证据**：日志 `saf.mkdir name=mark-readnotes` → `src.attach picked=Documents rootDocId=primary:Documents/mark-readnotes`。
- **状态**：已按此设计实现。

## P4 模拟器 AVD `test34` 起不来（环境问题）

- **现象**：容器 `notifbridge-emu` 启动 7 秒后 `Exited (1)`，日志
  `Failed to process .ini file …/test34.avd/config.ini` + `FATAL | CPU Architecture 'arm' is not supported`。
- **根因**：`~/.android/avd/test34.avd/` 下**没有 config.ini**（文件丢失），模拟器落到默认配置（arm）。
- **处置**：改用 `test35`（x86_64 / android-34 google_apis，配置完整）。不是应用缺陷，未改应用代码。
- **状态**：绕过（test34 需要重新 create AVD 才能用）。
