# 同步规格（WebDAV）：基线 + 冲突三选

用户 2026-09-22 的需求里就写了「支持 webdav」；做法**参考 waikr/KardLeaf**（Apache-2.0）的同步语义
（见 `THIRD-PARTY-NOTICES.md`）：基线记“上次同步时两边各什么样”，靠它判断谁动过；
两边都动过就是冲突，**不替用户选**，交给三选。本项目按自己的存储结构重写（远端路径＝本地相对路径）。

## 1. 谁同步什么

- **范围**：随笔目录里的 md（本地索引 `present=1` 且 `rel_path` 以 `随笔/` 开头）。
  图片、导出目录、别的板块的目录**都不参与**同步。
- **远端路径**：就是本地的相对路径，例如 `随笔/web.md`、`随笔/网摘/paper.md`
  （远端根 = 用户填的地址，例如 `https://nas:5006/dav/mark-readnotes`）。
- **一份数据一个权威源**：本地权威还是盘上的 md；同步只搬字节，不解析内容。

## 2. 基线（同步状态）

`sync_state` 表，一行一个文件：`rel_path` / `local_size` / `local_hash`(sha1) /
`remote_size` / `remote_mtime` / `remote_etag` / `synced_at`。
**只在真正传成功之后才写**；跳过冲突的不写（下次还会报）。

判断“谁动过”：

| 情况 | 判据 |
|---|---|
| 本地动过 | 没有基线，或 `size`/`hash` 与基线不同（或本地已不存在） |
| 远端动过 | 没有基线，或 `size`/`etag` 与基线不同（或远端已不存在） |

## 3. 计划（先算再做，不写任何东西）

| 本地 | 远端 | 基线 | 动作 |
|---|---|---|---|
| 有 | 无 | 无/本地动过 | **上传** |
| 无 | 有 | 无/远端动过 | **下载** |
| 有 | 有 | 无 | **冲突**（无从判断谁新） |
| 有 | 有 | 有，两边都动过 | **冲突** |
| 有 | 有 | 有，只有本地动过 | 上传 |
| 有 | 有 | 有，只有远端动过 | 下载 |
| 有 | 有 | 有，都没动 | 不用动 |
| 无 | 无 | 有 | 不用动（两边都删了） |
| 无 | 有 | 有，本地删过 | **冲突**（“本地已删除，远端还在”） |
| 有 | 无 | 有，远端删过 | **冲突**（“远端已删除，本地还在”） |

## 4. 执行

- **上传**：逐级 `MKCOL` 建目录 → `PUT` → 再 `PROPFIND` 读回 size/mtime/etag → 写基线。
- **下载**：`GET` → 写本地（没有就按相对路径建目录+建文件）→ 更新索引（重解析块）→ 写基线。
- **冲突**：一个字也不动，列出来。
- **失败**：逐条记进 `failed`（文件、动作、原因），不吞、也不假装成功。

## 5. 冲突三选

| 选择 | 做什么 |
|---|---|
| 保留本地 | 用本地内容 `PUT` 覆盖远端 → 写基线 |
| 保留远端 | `GET` 覆盖本地 → 重建索引 → 写基线 |
| 跳过 | 两边都不动，**不写基线** → 下次同步还会报（不替用户决定） |

## 6. 界面（功能 ↔ 板块 ↔ 按键 ↔ 判据）

| 项 | 规格 |
|---|---|
| 入口 | 设置小窗一行「WebDAV 同步」（显示服务器地址）+ 「打开」 |
| 配置 | 服务器 / 用户名 / 密码（`type=password`）+ 「测试」「保存」；**测试会先保存再连**，免得测的是旧配置 |
| 同步 | 「立即同步」：算计划 → 执行 → 提示“上传 N，下载 M，冲突 K” |
| 冲突 | 有冲突时多一行「冲突 K 个」+「逐个处理」→ 每个冲突一行，三键：保留本地 / 保留远端 / 跳过 |
| 凭证 | 只存在应用私有库的 `meta` 表里，**不上传、不进日志、不入档**；日志里只写服务器地址与“设过密码” |

## 7. 判据（S1–S8）

- **S1** 配置能存下、连接测试能过（`sync.test.ok=true`）；界面：设置里有入口、小窗里有服务器/账号输入框、
  密码框是 `password` 类型、测试/保存/同步三键在位，且**真点「测试」会去连**（提示里出现“能连上”）。
- **S2** 本地新增的文件被上传，且**服务器上的字节与本地一致**（宿主 `cmp`）。
- **S3** 两边都没动时，计划是“全都不用动”（上传 0、下载 0、冲突 0）。
- **S4** 远端新增的文件被下载到本地、内容一致、块进索引、主页块数 +1。
- **S5** 两边都改过 → 报冲突（原因“两边都改过”），执行同步时**冲突两边都不动**。
- **S6** 三选：保留本地 → 远端变成本地版本；保留远端 → 本地变成远端版本；跳过 → 下次还报（仍是 1 个冲突）。
- **S7** 验收造的文件收尾清干净（本地与远端）。
- **S8** 所有判据读的都是盘上/接口上的事实（`cmp`、`ls`、索引计数、`sync.plan` 回包），不看提示文案当证据
  （提示只作为 S1 里“真点了一次”的辅助证据）。

## 8. 明确不做（这一版）

- 双向实时同步 / 后台自动同步（现在只有用户点「立即同步」）
- 断点续传、大文件分块（笔记都是小文本）
- 删除传播的自动合并（“一边删一边改”一律按冲突报出来，让人定）
- 远端重命名映射（远端路径＝本地相对路径，不做远端专用结构）
