## F8 数学公式（本机 KaTeX，离线）

写一段含公式的块再切预览：
```
node tools/webview-cdp.mjs type '#ed-body' '行内 $E=mc^2$ … $$\n\int_0^1 x^2\,dx = \frac{1}{3}\n$$ … 坏公式 $\frac{1}{$'
node tools/webview-cdp.mjs tap '#btn-preview'
node tools/webview-cdp.mjs eval 'window.mrState().tex'
node tools/webview-cdp.mjs eval '({katex:document.querySelectorAll("#preview .katex").length, err:document.querySelectorAll("#preview .katex-error").length, display:document.querySelectorAll("#preview .katex-display").length})'
```
实测：`{"total":3,"ok":2,"failed":1}`、`{"katex":2,"err":1,"display":1}`
→ 行内公式与多行 `$$…$$` 各渲染出一个 KaTeX（含一个 display 块）；坏公式渲染成 `.katex-error` 显示原文，
页面照常（preview innerHTML 约 1.7KB，没有炸）。
资源来源：KaTeX 0.18.7 内置在 assets（`ui/vendor/katex`），页面上 `typeof window.katex === "object"`、`katex.version = 0.18.7`；
tarball 的 sha512 与 npm 声明一致（见 `evidence/katex-provenance.txt`）。**通过**

## F9 本地图片（md 里写相对路径，走笔记根解析）

笔记根里放 `pic.png`，`img/two.png` 子目录；块里写 `![本地图](pic.png)` 与 `![子目录图](img/two.png)`：
```
node tools/webview-cdp.mjs eval 'window.mrState().imgs'
adb shell logcat -d -s markreadnotes | grep img.
```
实测：`[{"src":"…/file/pic.png","ok":true,"w":64,"h":64},{"src":"…/file/img%2Ftwo.png","ok":true,"w":48,"h":48},…]`
原生日志：`img.serve rel=pic.png mime=image/png size=146`、`img.serve rel=img/two.png mime=image/png size=115`
→ 图片字节真的由原生按 SAF 从笔记根取出来（不是猜路径、也不是走 file://）。**通过**

## F11 基本 HTML 的消毒（安全，新增）

块里写 `<script>window.__pwned=2</script>`、`<img … onerror="…">`、`<a href="javascript:…">`、`<iframe …>`：
```
node tools/webview-cdp.mjs eval '({sanitize:window.__sanitize, pwned:window.__pwned, scriptInDom:document.querySelectorAll("#preview script").length, iframeInDom:document.querySelectorAll("#preview iframe").length, onerrorLeft:document.querySelectorAll("#preview [onerror]").length, jsHrefLeft:…, imgStillThere:document.querySelectorAll("#preview img").length})'
```
实测：`{"sanitize":{"removedTags":2,"removedAttrs":2},"pwned":"未被注入","scriptInDom":0,"iframeInDom":0,"onerrorLeft":0,"jsHrefLeft":0,"imgStillThere":1}`
→ 脚本/iframe 被移除、事件属性与 javascript: 链接被剥掉，正常图片不受影响。**通过**
