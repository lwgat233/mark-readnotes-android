## 0. 环境准备（每次重跑都要）


## F1 目录授权

```
（页面空态）node tools/webview-cdp.mjs tap '#btn-pick-empty'
（系统选择器）选一个子目录 → USE THIS FOLDER → ALLOW
adb shell "ls -ld /sdcard/Documents/mark-readnotes"
adb shell "run-as dev.markreadnotes cat databases/notes.db" > /tmp/n.db   # 用 python3 sqlite3 读
```
实测：`mark-readnotes` 目录已建；`source` 表 1 行，`tree_uri=content://com.android.externalstorage.documents/tree/primary%3ADocuments`；
日志 `saf.mkdir name=mark-readnotes` + `src.attach picked=Documents rootDocId=primary:Documents/mark-readnotes`。**通过**

## F2 新建块落盘（md 是权威源，SQLite 是索引）

```
node tools/webview-cdp.mjs tap '#btn-new'
node tools/webview-cdp.mjs type '#ed-heading' '…标题…'
node tools/webview-cdp.mjs type '#ed-tags' 'paper'
node tools/webview-cdp.mjs type '#ed-body' '…正文…'
node tools/webview-cdp.mjs tap '#btn-done'
adb shell "cat /sdcard/Documents/mark-readnotes/paper.md"
```
实测：`paper.md` 内容为首行 `# 标题`、次行 `#paper`、其后正文；`block` 表计数 +1，`tag=paper`。**通过**

## F3 主页 = 最近编辑的块（每块最高高度固定）

```
node tools/webview-cdp.mjs eval 'Array.from(document.querySelectorAll(".card")).map(c=>({head:c.querySelector(".b-head").textContent,tag:c.querySelector(".b-tags").textContent,h:Math.round(c.getBoundingClientRect().height)}))'
```
实测：`[{head:"PagedAttention 论文要点",tag:"#paper",h:124},{head:"视频随手记：KV Cache 那期",tag:"#web",h:148}]`
→ 最近编辑在前；高度 124/148 ≤ CSS 上限 `--card-max:148px`。**通过**

## F4 点块弹全屏白板（不是小窗口）

```
node tools/webview-cdp.mjs tap '.card'
node tools/webview-cdp.mjs eval '(()=>{const r=document.getElementById("board").getBoundingClientRect();return {x:r.x,y:r.y,w:r.width,h:r.height,vw:innerWidth,vh:innerHeight};})()'
```
实测：`{x:0,y:0,w:412.19,h:842.29,vw:412,vh:842}` → 与视口逐像素一致（键盘弹起时 vh 变 530，白板仍占满可视区）。**通过**

## F5 改第一个标签 = 整块搬家

```
node tools/webview-cdp.mjs tap '.card'
node tools/webview-cdp.mjs tap '#ed-tags'          # 聚焦即全选
node tools/webview-cdp.mjs type '#ed-tags' 'web'
node tools/webview-cdp.mjs tap '#btn-done'
adb shell "ls -l /sdcard/Documents/mark-readnotes"
adb shell "cat /sdcard/Documents/mark-readnotes/web.md"
```
实测：`unsortedweb.md` 消失（搬空即删），`web.md` 含该块且标签行变成 `#web`；
SQLite：`block.id=1` 不变，`file_id` 由 1（unsortedweb.md）→ 2（web.md），`updated_at` 前移。**通过**

## F6 懒扫描（不全局扫目录、索引永久保留）

```
adb shell am force-stop dev.markreadnotes && adb shell logcat -c && adb shell am start -n dev.markreadnotes/.MainActivity
adb shell logcat -d -s markreadnotes | grep -E "scan="
node tools/webview-cdp.mjs eval 'window.mrState().cards'
# 外部改文件（模拟电脑上改的），再打开这块：
adb shell "echo '外部追加的一行' >> /sdcard/Documents/mark-readnotes/web.md"
node tools/webview-cdp.mjs tap '.card'; adb shell logcat -d -s markreadnotes | grep scan=
```
实测：冷启动仅 `app.start … scan=skipped(reason=startup)`，其后全程只有 `scan=single(file=…,state=unchanged|changed)`，
没有 `scan=walk`；重启后主页立刻有 2 张卡片（只读 SQLite）；外部追加那行被读进正文（单文件校验真的重读了）。**通过**

## F7 归档（一级标题）与正文隔离

```
node tools/webview-cdp.mjs eval '(()=>{const c=document.querySelector(".card");const h=c.querySelector(".b-head");return {arch:c.querySelector(".b-arch").className,head:h.textContent,bodyHasHead:c.querySelector(".b-body").textContent.includes(h.textContent)};})()'
```
实测：`{arch:"b-arch",head:"视频随手记：KV Cache 那期",bodyHasHead:false}`。**通过**
