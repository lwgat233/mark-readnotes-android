## 本轮修掉的真缺陷

### P16 整理旧布局会把块在索引里变成两份

- **现象**：迁移后块数 8 → **15**（正好多一份），文件本身没错。
- **真因**：迁移是「在新位置建文件 → 写 → 删旧文件」，新文件的 docUri 变了 → 索引里多了一个 `note_file` 行；
  旧行名下的块行没有被改指，也没有被标掉 → 下次扫描给新行重新入库一遍块，**旧的还在**，于是重复。
- **修法**：搬家后 `repointBlocks(旧行 → 新行, 新 docUri)` 保住块的 id 与「最近编辑」顺序，再 `dropFile(旧行)`；
  另外给 `refresh` 加一条一致性收尾：文件都不在了，它名下的块一起标成不在（不留孤儿块）。
- **回归判据**：`store.migrate 搬完块数没变（D3）` + `store.migrate 该文件的块都在（D3）`。
