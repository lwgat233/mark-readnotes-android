## 第 4 轮（下一步，按用户原始需求排）

1. **导入**（用户原话：「根据哪个标签来导出文件，就根据哪个标签来导入文件，标签又不变」）：
   读回导出的目录 → 解析每个 md 的块 → 按同一套标签规则并回笔记夹，**标签不变**。
   开工前要跟用户定一件事：**同名/同标题的块怎么合并**（覆盖 / 并存并加后缀 / 跳过）。
2. **WebDAV**：远端当导出/导入目标（先做“能登录、能列目录、能读写单文件”，再做整根），
   规则与本地一致：只按需取单文件、索引永久保留、离线标 `present=0`。
3. 其余缺口见 `docs/缺口清单.md`。

## 用户原话式需求（不许走样）

- 笔记本体：「一级标题分块，可以随机添加块」「一级标题要归档、与文本隔离开」「标题后第一行就是多个标签」
  「第一个标签决定进哪个文件」「改第一个标签＝整块搬家」「主页给最近编辑的块，每块最高高度固定」
  「点块从下面弹出渲染白板，占全屏且不算小窗口」
  「sqlite 不要全局扫目录，要懒扫描、永久存储，不论是不是网络存储器」。
- 渲染：「支持图片等等基本语法」「解析网站并跳转」「支持基本 html」「支持 tex」（前三项已做，tex 用内置 KaTeX）。
- 导出（2026-09-22）：「按标签导出——第 1 个标签当一级目录、第 2 个当二级」「要有排除项：排除哪些标签不导出」
  「可以分享，也可以导出（打开系统接口放到指定目录）」「一个按键叫直接导出，一个叫导出并预览」。
- 存储位置：「默认选择一个用户可见的地方存储」「目录不要使用中文」（应用自建固定目录一律英文；
  导出目录是内容的一部分，用户已确认用标签原文）。

## 环境的硬约束（踩过的坑）

- 宿主内存 7.8G、无 cgroup 上限：构建与模拟器**串行**；Gradle `--no-daemon` + `-Xmx1024m`。
- google() 不可达 → 阿里云镜像；前端三方资源走 npmmirror 并校验 npm 声明的 integrity。
- 模拟器用 **AVD test35**；`AVD=test35 bash /vol1/1000/aicache/docker/emu.sh start`。
  启动后会遇到 nexuslauncher ANR 抢焦点 → `am force-stop com.google.android.apps.nexuslauncher` 再 dump 界面。
- 装包前先证明构件里有启动类：`unzip -p apk classes3.dex | strings | grep -c Ldev/markreadnotes/MainActivity;`
- 批量改文件别用 `open(p,'w').write(open(p).read()…)`（先截断再读 = 写空）；用 patch 工具。
- 设备上别用 `adb shell grep 中文模式` 判内容（会被搞坏成假阴性）——`cat` 回本地再判。
- 壳子走 http 虚拟源（为放行 http 图片，见问题登记 P5）；分享用 FileProvider（不需要存储权限）。
