## 用户原话式需求（不许走样）

- 「按照一级标题来分成不同块，可以随机添加块」——块顺序自由；主页只按最近编辑排。
- 「一级标题要给一个归档（与文本隔离开来）」——标题与标签行独立成块，不混进正文。
- 「标题后第一行就是多个标题」「第一个 tag 文本不是第一行」→ 标签行在一级标题后第一行、可多个；
  **取第一个决定进哪个 md 文件**；判定按块内按行顺序找，不写死“紧邻标题那一行”。
- 「支持修改第一个标签，达成将这一块文件移动到其他文件」——改标签=整块搬家（旧文件删、新文件追加）。
- 「主页是给出最近编辑的块，每块渲染最高高度固定」「点击块后就从下面弹出渲染白板，开始编辑，
  白板占据全屏且不算小窗口」。
- 「sqlite 最后不要直接全局扫描目录，要扫描的话就下次是懒扫描，永久存储且不论是不是网络存储器」。
- 「默认选择一个指定用户可见地方存储产生文档」「目录不要使用中文」→ SAF 选目录 + 固定英文子目录 `mark-readnotes`。

## 环境的硬约束（踩过的坑）

- 宿主内存 7.8G、无 cgroup 上限：构建与模拟器**串行**；Gradle `--no-daemon` + `-Xmx1024m`。
- google() 不可达 → 阿里云镜像（settings.gradle.kts 里已配）。
- 模拟器：AVD 用 **test35**（test34 的 config.ini 丢了，会退化成 arm 架构起不来）；
  启动 `AVD=test35 bash /vol1/1000/aicache/docker/emu.sh start`。
- 前端不用 `file://`；桥用 `addWebMessageListener`，页面必须自己挂 `onmessage`。
- SAF **不能选内部存储根目录/Download 根**（系统会说 Can't use this folder）→ 设计成让用户选一个子目录，
  应用在其中自建 `mark-readnotes`。
- 交付前必须真跑：`adb install` + CDP 读真实 DOM（tools/webview-cdp.mjs）。
