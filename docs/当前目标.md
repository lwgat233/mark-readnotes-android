## 用户原话式需求（不许走样）

- 「按照一级标题来分成不同块，可以随机添加块」——块顺序自由；主页只按最近编辑排。
- 「一级标题要给一个归档（与文本隔离开来）」——标题与标签行独立成块，不混进正文。
- 「标题后第一行就是多个标题」「第一个 tag 文本不是第一行」→ 标签行在标题后第一行、可多个；
  **取第一个决定进哪个 md 文件**；判定按块内按行找，不写死行号。
- 「支持修改第一个标签，达成将这一块文件移动到其他文件」——改标签=整块搬家。
- 「主页给出最近编辑的块，每块渲染最高高度固定」「点击块后从下面弹出渲染白板…占据全屏且不算小窗口」。
- 「sqlite 不要直接全局扫描目录…下次是懒扫描，永久存储且不论是不是网络存储器」。
- 「支持图片等等基本语法，能够解析网站并跳转，支持基本 html 语法，支持 tex 语法」——第 2 轮已做；
  跳转走系统浏览器（`ui.open`），HTML 放行但先消毒。
- 「默认选择一个指定用户可见地方存储产生文档」「目录不要使用中文」→ SAF 选目录 + 固定英文子目录 `mark-readnotes`。

## 环境的硬约束（踩过的坑）

- 宿主内存 7.8G、无 cgroup 上限：构建与模拟器**串行**；Gradle `--no-daemon` + `-Xmx1024m`。
- google() 不可达 → 阿里云镜像；KaTeX 等前端资源走 npmmirror 并校验 npm 声明的 integrity。
- 模拟器用 **AVD test35**（test34 缺 config.ini 会退化成 arm）；启动
  `AVD=test35 bash /vol1/1000/aicache/docker/emu.sh start`。
- 装包前先证明构件里有启动类：`unzip -p apk classes3.dex | strings | grep -c Ldev/markreadnotes/MainActivity;`
  （源文件被写空时构建照样成功，装上去才崩 `ClassNotFoundException`）。
- 壳子走 **http 虚拟源**（原因见问题登记 P5）：笔记里的 http 图片才出得来。
- 批量改文件别用 `open(p,'w').write(open(p).read()…)`（先截断再读=写空）；用 patch 工具。
- 设备上别用 `adb shell grep 中文模式` 判内容（会被搞坏成假阴性）——把文件 `cat` 回本地再判定。
