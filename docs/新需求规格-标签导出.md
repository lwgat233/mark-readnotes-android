# 新需求规格：按标签导出 / 导入（随笔）

用户 2026-09-22 提出。同批需求里还有 WebDAV（后面单开一轮）。

## 1. 能不能做（先回答五个问题）

1. **输入 / 输出**：输入 = 已索引的块（SQLite 里 present=1 的块，含标题、标签、正文原文）；
   输出 = 按标签生成的 `<标签>/…/<标题>.md` 文件（写到用户选的目录，或交给系统分享）。
2. **怎么算做到**（判据都是读回来的事实）：
   - 目录树：`adb shell ls -R` / SAF 列目录，看到 `法规/标准/…`、`法规/2024/…` 这类结构；
   - 内容：读回生成文件，与库里的块原文一致（标题、标签行、正文都在，标签不变）；
   - 排除：勾选排除的标签，结果里既没有它的目录也没有它的块，且汇总数字对得上；
   - 分享：拉起系统分享（chooser 真的出现在前台 + 日志里记下 action、uri 数、解析到的目标）；
   - 预览：预览后**不产生任何文件**（对比导出前后目标目录条目数不变）。
3. **要靠什么能力**：SAF 目录授权（已有）、读 SQLite（已有）、写 SAF 子目录（已有 `ensureDir`/`createMd`）、
   `Intent.ACTION_SEND_MULTIPLE` + `FileProvider`（新增，需清单声明 provider 与 `file_paths.xml`）。
4. **没有的能不能绕过**：都能做，不需要新权限（分享靠 FileProvider 给临时 content:// 授权，不要存储权限）。
5. **失败时退化成什么**：选目录失败/分享没有可接收的应用 → 如实提示（“没有能接收的应用”），
   不写半截文件（先全部生成到应用缓存，落盘/分享是一步原子的复制）。

## 2. 规则（数据模型）

- **块**：沿用现有定义（一级标题分块；标题后第一行是标签行，可多个）。
- **目录层级 = 标签顺序**（用户选定）：第 1 个标签 → 一级目录，第 2 个 → 二级目录，第 3 个及以后**不参与建目录**
  （但仍原样留在文件里的标签行中）。例：`#法规 #标准 #2024` → `法规/标准/<标题>.md`。
- **文件名** = 一级标题（去掉路径非法字符 `\ / : * ? " < > |`，最长 60 字符）；同级重名追加 `-2`、`-3`。
- **排除标签**：导出界面里可勾选若干标签；“带**任一**排除标签的块整体不导出”（不建目录、不写文件）。
- **每个文件 = 一个块**：文件内容就是该块的原文（`# 标题` + 标签行 + 正文），
  这样**导入时能用同一套规则原样归位，标签不变**。
- **导出根**：用户第一次导出时通过系统目录选择器指定，应用在其中自建英文子目录 `mark-readnotes-export`
  （应用自建的固定目录一律英文，与“目录不要中文”的约定一致）。
- **分享**：先全部生成到应用缓存 `cacheDir/share/<规则目录结构>`，再用 FileProvider 生成 content:// 一次性授权给
  `ACTION_SEND_MULTIPLE`（多文件）或 `ACTION_SEND`（单文件）。

## 3. 界面（功能 ↔ 板块 ↔ 按键 ↔ 判据）

| 项 | 规格 |
|---|---|
| 入口 | 主页顶栏「导出」（与「设置」并列；主页常驻按键总数 = 3：导出、设置、＋新随笔） |
| 载体 | 底部小窗（盖在白板之上，层级 `#sheet` 高于 `#board`） |
| 小窗内容 | 规则说明一行（“按标签顺序建目录”）＋ 排除标签（可点选的标签列表，来自库里出现过的标签）＋ 汇总行（多少块、多少文件、排除几块） |
| 按键 1 | **导出并预览**：列出将生成的文件树（目录 + 文件名 + 每文件块数），**不写盘**；预览后底部出现下面两个动作键 |
| 按键 2 | **直接导出**：跳过预览，直接执行（默认写到导出目录；写目录前先确认一次路径） |
| 动作键 A | 写入目录（首次会弹系统目录选择器）；完成后给结果清单（写到哪、几个文件） |
| 动作键 B | 系统分享（把生成的文件交给别的 App） |
| 空态 | 一个块都没有时：「还没有随笔，先记一条再来导出」 |

## 4. 本版不做（写清缺口）

- **导入**（把导出的 md 目录按同样规则并回笔记夹）：规则已定（同一套标签规则、标签不变），
  但冲突处理（同标题同名块怎么办）要先跟你定，放下一轮。
- **WebDAV**：远端只读/读写、离线标记、缓存策略，单独一轮。
- 导出到 .zip 打包：用户这次点名的是“系统分享”和“写到指定目录”，zip 不做。

## 5. 稳定标识（测试与自检用）

- 页面：`#btn-export`（主页顶栏）、`#export-sheet` 里的 `#ex-preview` / `#ex-run` / `#ex-to-dir` / `#ex-share`、
  `#ex-tree`（预览文件树）、`#ex-summary`（汇总行）、`.ex-tag`（可排除的标签项）
- op 层：`exp.plan`（算规则，回文件树+汇总）/ `exp.writeDir`（写到导出目录）/ `exp.share`（系统分享）
- 日志：`exp.plan(files=…,blocks=…,excluded=…)`、`exp.write(dir=…,files=…)`、`exp.share(uris=…,target=…)`
