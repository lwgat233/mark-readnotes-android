# 渲染：现在到哪了，后面怎么做（第 9 轮记，2026-09-22）

用户原话：**「你不做，但是这些渲染的，你还是要提示一下后面到底要怎么做。」**
所以这份不是计划表，是**施工说明**：每一项都写清「目标 → 改哪里 → 怎么做 → 判据怎么写 → 什么坑」。
本轮不动渲染；将来谁做（或哪一轮做）照着抄即可，不用重新摸一遍。

- 结构能力：标题/列表/嵌套/引用/代码/表格/任务清单（真勾选框）/四种公式写法/原始 HTML 图，判据 `render.sh` 29 条。

## 1. 代码块复制键

- **目标**：每个 `pre` 右上角一个「复制」，点一下把代码原文放进剪贴板。
- **改哪里**：`assets/ui/render.js` 的 `renderInto`（挂载前给每个 `pre` 套一层 `.code-wrap` 并塞按钮）；样式进 `app.css`。
- **怎么做**：**不要用 `navigator.clipboard`** —— 我们的页面走 http 虚拟源，不是安全源，`clipboard` 会被拒；
  走原生：新增 op `ui.copy{text}` → `UiOps` → `ClipboardManager`。按钮点击时取 `pre.textContent`（原文）传过去。
- **判据**：`render.sh` 加两条 —— ① 每个 `pre` 里有一个 `.code-copy`；② 点第一个 → 原生里读剪贴板内容 == `pre` 文本
  （原生侧读剪贴板可以用 `adb shell service call clipboard` 或让 `ui.copy` 回包带上写入长度，再断言长度 > 0）。
- **坑**：别在渲染层用 `innerHTML` 拼按钮（笔记内容可能含 `</pre>`）。

## 2. 点预览定位源码偏移（参照实现里那套）

- **目标**：点预览里的某一段，编辑区光标跳到源码对应位置。
- **改哪里**：`render.js`（渲染时给每个块级节点记行号）+ 白板编辑区（`board.js`）。
- **怎么做**：markdown-it 的每个 token 带 `token.map = [startLine, endLine]`。渲染时把 `data-line` 写到对应的
  DOM 节点上（在 `renderInto` 里遍历 `md.parse()` 的结果，或用 markdown-it 的 `renderer.rules` 包一层加属性）。
  点击时：把行号换算成源码字符偏移（按 `\n` 累计），对编辑区 `setSelectionRange(offset, offset)` 并滚动过去。
- **判据**：`render.sh` —— ① 第 n 个 `h2` 上有 `data-line` 且等于源码里那行的行号；② 点它之后编辑区 `selectionStart`
  落在源码里该标题的字符偏移 ±1。
- **坑**：**第 19 轮换 CodeMirror 之后再做这件事更划算**（现在 textarea 只能按字符偏移定位，CodeMirror 有行号 API）。

## 3. 点图片放大（图片查看器）

- **目标**：点预览里的图 → 全屏看原图（可再点「保存」）。
- **改哪里**：`render.js` 给 `img` 存 `data-src`；新增一个浮层（复用 `sheet` 机制）+ op `img.save{src}`。
- **怎么做**：点击开浮层，`<img src=data-src>` 撑满；「保存」调 `img.save`，原生把它复制到导出目录或系统相册。
- **判据**：① 点图后浮层出现；② 浮层里 `img.naturalWidth` == 原图宽（不是 0、不是缩略图宽）。
- **坑**：图在随笔目录里是 `content://`（SAF），WebView 需要一个能长期读的 URL —— 沿用现在预览那条 `/file/` 虚拟源路径。

## 4. 外链图片本地化（很重要，不然网页图早晚失效）

- **目标**：`![](https://…)` 的图，导入时下载进随笔目录，md 里改成本地相对路径。
- **改哪里**：新 op `src.saveImage{url|base64}` → `NotesRepo`（写盘）+ OkHttp（已有依赖）拉图。
- **怎么做**：下载 → 按**内容哈希**命名（`assets/<hash8>.<ext>`，ASCII，避免中文名/重名）→ 返回相对路径 →
  前端把 md 里的 URL 换掉（只在用户点「本地化图片」时做，不偷偷改）。
- **判据**：① 调 `src.saveImage` 后文件真的在随笔目录里、大小 > 0；② md 里的 URL 变成相对路径；
  ③ 关掉网络后预览里 `naturalWidth > 0`（证明是本地那份）。
- **坑**：`http` 图片要走 Clash/直连会失败时要有明确报错，别静默留个空 `img`（也别忘了 `usesCleartextTraffic` 已开）。

## 5. 更多 markdown 语法（按需一个一个加）

- **做法**：完全照 `tools/fetch_vendor.py` 的路子 —— npm 下载 → 校验 integrity → 放进 `assets/ui/vendor/<名字>/` →
  `index.html` 按序加载 → `render.js` 里注册；出处补进 `THIRD-PARTY-NOTICES.md`。
- **候选与插件**：
  - 脚注：`markdown-it-footnote`
  - 定义列表：`markdown-it-deflist`
  - 上下标：`markdown-it-sub` / `markdown-it-sup`
  - `==高亮==`：`markdown-it-mark`
  - 代码语法高亮：离线 `highlight.js`（或 Prism）的压缩包 —— 体积换观感，先问用户要不要，别默认加
- **判据**：每加一个插件，`render.sh` 补 2 条 DOM 断言（结构 + 交互，例如脚注：正文出现上标 + 底部出现脚注段）。

## 6. KaTeX 扩展（化学式/物理）

- **怎么做**：拉 `katex/contrib/mhchem.min.js`（同版本 0.18.7），在 `texmath.js` **之前**加载；`\ce{...}` 就能认。
- **判据**：`render.sh` 加一条 —— `\ce{H2O}` 渲染出 `.mhchem` 或对应节点，`.katex-error` 数量为 0。

## 7. 性能（到几万字再管）

- **现状**：整篇一次渲染，实测 45ms（判据 `ms < 400`），不需要动。
- **做法**：真要优化就按块渲染 —— 白板里只有"当前块"需要重渲染，`renderInto` 改成接收块文本、只重挂该块的结果。
- **判据**：一万字文档渲染 < 400ms；连续编辑 20 次后 DOM 节点数不增长（证明没有重复挂载）。

## 8. 样式收尾（只在有需求时做，不主动改）

- 已做：见 §0 已做清单（表格/代码/引用/图片/公式/标题那一套）。
- 还没做、且用户没提的：字号三档设置（存 prefs，默认中）、深浅色跟随系统、有序列表多级缩进美化。
- **规矩**：改样式一律**只动 `app.css` 里 `.preview`/`.searchbar` 这些隔离段**，不许碰布局骨架（主页/白板的位置关系）。

## 9. 消毒的后续边界（安全红线，改渲染时必看）

- 白名单要**同时管标签与属性**；URL 只放行 `http/https/mailto` 与相对路径（`javascript:`、`data:` 一律砍）。
- **KaTeX 的输出要整棵放行**：按标签逐个白名单会把公式的 `<span class="katex">` 家族吃掉（踩过）。
- **绝不要退回到逐 token 消毒**：会把成对的行内 HTML（`<span style="color:red">字</span>`）拆散（踩过 P15）。
- 预览里的 HTML 只在"游离容器里解析 → 整体过滤 → 再挂进页面"这一条路上走。

## 10. 判据怎么写（渲染板块的规矩）

- 渲染能力一律**加在 `tools/boards/render.sh`**（渲染板块），别再往随笔板块塞；命名 `render.xxx 判据名`。
- 一个能力**至少两条断言**：结构（DOM 里有几个什么）+ 交互（点了之后发生什么）；只数结构＝没验行为。
- 假红防护照现在的做法：`#preview` 里的东西要可见才查（先 `scrollIntoView`），背景态操作前先 `refocus_app`。
